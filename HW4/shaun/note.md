What is the DOM?
The DOM (Document Object Model) is a tree-like representation of an HTML document that JavaScript can interact with.
How can you select an HTML element using JS?
HTML elements can be selected using methods such as getElementById, querySelector, and querySelectorAll.
What is a DOM event?
A DOM event is an action or occurrence, such as a click or keypress, that happens in the browser.
How do we register event handlers for a selected element?
Event handlers are commonly registered using the addEventListener() method.
Explain event delegation. Why is it important?
Event delegation attaches a single event listener to a parent element to handle events from its children, improving performance and maintainability.
What is event propagation? How many phases are there? In what order does it occur?
Event propagation is the process of an event moving through the DOM, occurring in three phases: capturing, target, and bubbling.
Explain event bubbling and event capturing.
Event capturing propagates events from the document down to the target, while event bubbling propagates events from the target back up.
What function prevents the bubbling behavior？
The event.stopPropagation() method prevents an event from bubbling up the DOM tree.
What is an IIFE
An IIFE (Immediately Invoked Function Expression) is a function that runs immediately after it is defined.
What is the use of the preventDefault method?
preventDefault() prevents the browser's default behavior for an event.
Can you name some of the new ES6 features?
ES6 introduced features such as let, const, arrow functions, classes, template literals, destructuring, promises, and modules.
