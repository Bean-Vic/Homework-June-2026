What is HTML?
HTML (HyperText Markup Language) is the standard markup language used to create and structure web pages.
What is the minimal structure of an HTML5 document?
An HTML5 document minimally consists of <!DOCTYPE html>, <html>, <head>, and <body>.
What is the purpose of the meta tag?
The <meta> tag provides metadata about the webpage, such as character encoding, viewport settings, and SEO information.
What is the difference between <head> and <header>?
<head> contains document metadata, while <header> contains introductory content displayed on the page.
What element can we use to create a dropdown list?
The <select> element is used to create a dropdown list.
What is the <form> tag used for in HTML?
The <form> tag is used to collect and submit user input to a server.
Explain the rel="noreferrer nofollow" attribute in <a> tag? How can we open the link in a new tab?
noreferrer prevents the browser from sending referrer information, and nofollow tells search engines not to follow the link. Use target="_blank" to open the link in a new tab.
How do you serve your page in multiple languages?
Use internationalization (i18n) by providing translated content and setting the lang attribute appropriately.
What are semantic HTML tags, and why are they important?
Semantic HTML tags describe the meaning of content, improving accessibility, SEO, and code readability.
What’s the difference between SVG and Canvas?
SVG is vector-based and scalable without quality loss, while Canvas is pixel-based and better for complex graphics and animations.
