# Project Brief

This backend practice focuses on building small command line tools with Node.js.

The goal is to understand how to read local files, handle command line arguments, and print useful file information in the terminal.

For this task, I created a file summary tool. It accepts either a file path or a directory path. When the input is a file, the program prints the file name, extension, absolute path, file size, line count, and word count.

If the input is a directory, the program checks the markdown and text files inside it and prints a summary for each one. The results are sorted by file size.
