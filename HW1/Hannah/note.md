1. What is HTML?
   HyperText Markup Language. It defines the meaning and structure of web contents.
2. What is the purpose of the <meta> tag?
   <meta> provides metadata which is the information about the document rather than the contens on web pages.
3. What is the minimal structure of an HTML5 document?
   An HTML5 document needs a doctype, an html element which contains a head section for metadata, and a body section for visible page contents.
4. What is the difference between <head> and <header>?
   <head> is the section for metadata which doesn't display on the webpages, but <header> is an html tag used to display introductory information about the webpage.
5. What element can we use to create a dropdown list?
   <select> creates a drop-down list, with each choice represented by an <option> element.
6. What is the <form> tag used for in HTML?
   It's used to collect users' inputs and selections, which is usually sent to a server for processing.
7. Explain the rel="noreferrer nofollow" attribute in the <a> tag. How can we open the link in a new tab?
   "noreferrer" prevents sending the referrer URL, and "nofollow" means not passing SEO(Search Engine Optimization) ranking through this link. Use target="blank" attribute in the <a> tag.
8. How do you serve your page in multiple languages?
   Use the lang="" attribute in the <html> tag to specify languages, and create independent page for each language, and also provide an option for users to select different languages.
9. What are semantic HTML tags and why are they important?
   Semantic tags clearly describe the meanings of the contents on webpages, and they make the webpage eaiser to understand.
10. What’s the difference between SVG and Canvas?
    <svg>(Scalable Vector Graphics) draw vector graphics using XML-based markup. Each shape inside SVG is a real DOM element. <canvas> provides a bitmap drawing surface. Graphics are drawn using JavaScript, not HTML elements.
