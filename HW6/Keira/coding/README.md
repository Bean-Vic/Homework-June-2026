# Mini Shopping Cart

This is a self-contained mini shopping cart package. It runs directly in the browser with no install step, no build tool, and no internet connection.

## Open the app

Double-click `index.html`, or open it from your browser with File > Open.

## What is included

- `index.html` - the page users open.
- `styles.css` - all app styling.
- `app.js` - the class-style component, internal state, cart actions, and localStorage persistence.

## Features

- Select a product from a dropdown.
- Enter a quantity.
- Add the selected product to the cart.
- View item, quantity, price, line total, and cart total.
- Increase or decrease quantities after adding.
- Remove items from the cart.
- Persist the last cart in `localStorage` so it reloads on the next visit.
