1. What is CSS?
   CSS (Cascading Style Sheets) is used to control the appearance and layout of web pages.
2. What is block element? How is it different from inline, and inline-block elements?
   Block elements take up the full width of their container, inline elements only take up the space they need, and inline-block elements combine inline flow with block sizing capabilities.
3. What is the difference between pseudo-class and pseudo-element?
   A pseudo-class targets a specific state of an element, while a pseudo-element targets a specific part of an element.
4. What is the difference between the child combinator and the descendant combinator?
   The child combinator (>) selects only direct children, while the descendant combinator (space) selects all nested descendants.
5. What is the attribute selector? Give some examples.
   An attribute selector selects elements based on their attributes, such as input[type="text"] or a[target="_blank"].
6. What are two ways that we can make an element invisible? What is the difference?
   display: none removes the element from the layout, while visibility: hidden hides it but preserves its space.
7. What is the CSS Box Model? Describe each part.
   The CSS Box Model consists of content, padding, border, and margin, which together determine an element's size and spacing.
8. What is the usage of !important? What are some use cases?
   !important gives a CSS rule higher priority and is commonly used to override conflicting styles.
9. What does z-index do?
   z-index controls the stacking order of overlapping positioned elements.
10. Can padding and margin be negative?
    Margin can be negative, but padding cannot be negative.
11. How do you center a block element with CSS?
    A block element can be horizontally centered using margin: 0 auto when it has a defined width.
12. What are grid items? Can you explain some grid item properties?
    Grid items are the direct children of a grid container, and properties like grid-column and grid-row control their placement.
13. What is a flex container? Can you explain some flex container properties?
    A flex container is an element with display: flex, and properties like justify-content, align-items, and flex-direction control item layout.
14. What is responsive web design? How do we achieve this?
    Responsive web design ensures a website adapts to different screen sizes using techniques such as media queries, flexible layouts, and relative units.
