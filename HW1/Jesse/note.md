# HTML Interview Questions and One-Sentence Answers

## 1. What is HTML?

**Answer:** HTML is the language we use to build the structure of a web page.

## 2. What is the purpose of the `<meta>` tag?

**Answer:** The `<meta>` tag gives the browser extra information about the page, like encoding, viewport, description, or SEO data.

## 3. What is the minimal structure of an HTML5 document?

**Answer:** A basic HTML5 page usually has `<!DOCTYPE html>`, `<html>`, `<head>`, and `<body>`.

## 4. What is the difference between `<head>` and `<header>`?

**Answer:** `<head>` is for page information that users usually don’t see, while `<header>` is a visible section at the top of a page or section.

## 5. What element can we use to create a dropdown list?

**Answer:** We use `<select>` and `<option>` to make a dropdown list.

## 6. What is the `<form>` tag used for in HTML?

**Answer:** The `<form>` tag is used to collect user input, like login info, search text, or contact details.

## 7. Explain the `rel="noreferrer nofollow"` attribute in `<a>` tag. How can we open the link in a new tab?

**Answer:** `rel="noreferrer nofollow"` means the link won’t send referrer info and search engines shouldn’t follow it; to open a link in a new tab, we use `target="_blank"`.

## 8. How do you serve your page in multiple languages?

**Answer:** We can support multiple languages by creating localized pages, setting the right `lang` value, and using `hreflang` for SEO.

## 9. What are semantic HTML tags, and why are they important?

**Answer:** Semantic HTML tags are tags with clear meaning, like `<nav>`, `<main>`, and `<article>`, and they make the page easier to read, more accessible, and better for SEO.

## 10. What’s the difference between SVG and Canvas?

**Answer:** SVG is better for scalable graphics like icons and logos, while Canvas is better for drawing things dynamically, like games or animations.
