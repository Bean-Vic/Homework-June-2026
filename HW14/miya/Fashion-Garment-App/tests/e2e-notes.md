
I tested the core workflow manually:

1. Start the app with `npm start`.
2. Open `http://localhost:3000`.
3. Upload a garment image.
4. Confirm the image appears in the visual grid.
5. Confirm AI-style metadata is generated.
6. Search by a keyword in the description, such as `streetwear` or `denim`.
7. Filter by garment type, style, material, season, or occasion.
8. Add designer notes and tags.
9. Search again using the designer note text.
10. Confirm the updated image still appears correctly.

This covers upload, classify, search, filter, and annotation behavior end to end.
