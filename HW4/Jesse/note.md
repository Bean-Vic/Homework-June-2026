

1. **What is the DOM?** The DOM is a tree-like object model that represents the HTML elements on a web page.

2. **How can you select an HTML element using JS?** You can select an element with methods like `querySelector()`, `querySelectorAll()`, `getElementById()`, or `getElementsByClassName()`.

3. **What is a DOM event?** A DOM event is something that happens in the browser, such as a click, input, key press, or page load.

4. **How do we register event handlers for a selected element?** We register event handlers by calling `addEventListener()` on the selected element.

5. **Explain event delegation. Why is it important?** Event delegation means putting one listener on a parent element to handle events from child elements, which reduces repeated code.

6. **What is event propagation? How many phases are there? In what order does it occur?** Event propagation is how an event travels through the DOM in three phases: capturing, target, and bubbling.

7. **Explain event bubbling and event capturing.** Event capturing travels from parent to child, while event bubbling travels from child back to parent.

8. **What function prevents the bubbling behavior?** `event.stopPropagation()` prevents an event from bubbling to parent elements.

9. **What is an IIF?** An IIFE is a function expression that runs immediately after it is created.

10. **What is the use of the `preventDefault` method?** `event.preventDefault()` stops the browser's default action for an event.

11. **Can you name some of the new ES6 features?** ES6 added features such as `let`, `const`, arrow functions, template literals, classes, promises, and destructuring.
