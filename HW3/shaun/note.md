1. What is dynamic typing?
   JavaScript is dynamically typed, meaning variable types are determined at runtime and can change during execution.
2. Explain the difference between var, let, & const.
   var is function-scoped, while let and const are block-scoped, and const cannot be reassigned after initialization.
3. What is immutability? What data types in JS are immutable?
   Immutability means a value cannot be changed after creation, and all primitive types in JavaScript are immutable.
4. What is the difference between == and ===?
   == compares values after type conversion, while === compares both value and type without conversion.
5. What is difference between undefined and null?
   undefined means a value has not been assigned, while null represents an intentional absence of value.
6. List falsy values in JS.
   The falsy values are false, 0, -0, 0n, "", null, undefined, and NaN.
7. Explain hoisting in JavaScript.
   Hoisting is JavaScript's behavior of moving declarations to the top of their scope before execution.
8. Explain variable shadowing in Javascript.
   Variable shadowing occurs when an inner scope variable has the same name as an outer scope variable and hides it.
9. What are 3 ways to declare functions?
   Functions can be declared using function declarations, function expressions, and arrow functions.
10. What is a callback function?
    A callback function is a function passed as an argument to another function and executed later.
11. What’s the difference between primitive data types and reference data types in JS?
    Primitive types store actual values, while reference types store references to objects in memory.
12. What’s the difference between array for loop and forEach?
    A for loop provides full control over iteration, while forEach automatically iterates through each array element.
13. What’s the difference between array map and forEach?
    map returns a new transformed array, while forEach executes a function for each element without returning a new array.
14. What is the difference between array slice and splice?
    slice returns a copied portion of an array without modifying it, while splice modifies the original array by adding, removing, or replacing elements.
15. What is an arguments object?
    The arguments object is an array-like object that contains all arguments passed to a function.
